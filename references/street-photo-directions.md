# 街拍方向（按需选用）

这些方向改写自截图中的 A–H 可控延伸。每次选一个主方向和一个具体动作；用户的本人照片始终是人脸身份参考。不要默认一次生成全部方向。

| 方向 | 可变化内容 | 应固定或检查的内容 |
| --- | --- | --- |
| A 完整穿搭 | 全身构图、服装层次、鞋袜与配饰 | 双脚入镜、面容与身体比例自然 |
| B 局部穿搭 | 半身或三分之二构图、织物和配饰细节 | 面部特征、服装衔接、手部姿势 |
| C 日常事件 | 等车、推门、看橱窗、整理头发等一个小动作 | 事件合理，不堆叠动作 |
| D 机位变化 | 正面、侧前方、略低或略高的手机拍摄角度 | 机位变化后仍能辨认同一张脸 |
| E 环境互动 | 坐椅子、靠栏杆、拿咖啡等自然互动 | 支撑关系、手与道具接触真实 |
| F 原场景换姿势 | 背景与穿搭不变，仅微调姿态和视线 | 背景、衣物、面容不漂移 |
| G 新场景 | 从室内到街道、公园或车站等 | 原照仍作身份参考；新场景要有具体行动 |
| H 新穿搭与气氛 | 用户指定的新风格、时间或天气 | 仅改变获准要素，面部结构保持 |

每张图写明一个事件、一个主要动作、一个明确注意力对象，以及可用的自然光或手机补光。真实街拍感优先于复杂摆拍。若用户需要文案提示词，可输出简洁的中文场景说明与完整生图提示词；若用户要求图片，则直接生图并检查结果。
